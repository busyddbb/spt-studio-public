# 存放说明

这个「工作区」文件夹就是 SPT 的资料库。东西按下面的位置放好，SPT 就能自动认出来：显示预览、一键复制提示词、搜索、导出表格。

放好以后，SPT 几秒内会自己读到。没看到的话，点右上角「刷新」。

## 一眼看懂

```
工作区/
├── 运营/                          ← 一个专业一个文件夹（运营、电影、人像、品牌……名字随你）
│   └── 2026-10-20-AK-五道菜轮播/  ← 一件作品一个文件夹
├── 提示词/                        ← 好用、想反复用的提示词
├── 素材/                          ← 衣服、场景、镜头、音乐等素材表，以及参考图片
├── 记录/                          ← 日常记录、复盘、心得
├── 便签/                          ← SPT「便签」页的便签（按分组，也能看月历）
└── skills/                        ← 给 AI 用的技能（不懂可以不管）
```

`提示词`、`素材`、`记录`、`便签`、`skills` 这五个名字是固定的，不要拿来当专业名。

工作区不一定要放在软件文件夹里：到 SPT「设置 › 工作区」可以换成任何文件夹。

## 1. 作品

**文件夹名格式：`日期-客户-主题`**，例如 `2026-10-20-AK-五道菜轮播`。

- 日期写开始做的那天，格式 `2026-10-20`
- 客户名里不要有 `-`；自己的作品就写 `自家`
- 名字格式不对，SPT 认不出是作品

作品文件夹里这样放：

| 放什么 | 叫什么 | 说明 |
|---|---|---|
| 第一版素材和提示词 | `V1/` 文件夹 | 改了提示词再做一版，就新建 `V2/`，`V1` 不要动 |
| 按顺序上传的图 | `V1/01_xxx.jpg`、`02_xxx.jpg` | 前面的数字就是顺序 |
| 这一版的提示词 | `V1/正文.txt` | 整段提示词贴进去 |
| 只看不传的参考 | `V1/参考_xxx.jpg` | 文件名以「参考_」开头 |
| 生成好下载回来的 | `V1/回片1.mp4` | |
| 最终成片 | `成片.mp4` | 放作品根目录 |
| 封面 | `封面.jpg` | 放作品根目录，SPT 用它当卡片封面 |
| 做的过程和结果 | `记录.md` | 为什么这样做、改了什么、发没发 |
| 发布文案 | `发布包.md` | |
| 一组多张图的提示词 | `提示词-1.md`、`提示词-2.md` | 每张一份 |

例子：

```
运营/2026-10-20-AK-五道菜轮播/
├── 封面.jpg
├── 成片.mp4
├── 记录.md
├── 提示词-1.md
└── V1/
    ├── 01_小笼包.jpg
    ├── 正文.txt
    └── 回片1.mp4
```

## 2. 提示词

好用的提示词，一份存成一个 `.md` 文件，按类别放进子文件夹：

```
提示词/
├── 菜品/
│   ├── 色面棚拍.md
│   └── 色面棚拍.jpg      ← 同名图片会当效果图显示
└── 人像/
    └── 室内自然光.md
```

文件里直接写提示词就行。想加标签和说明，在最上面加这几行（可以不加）：

```
---
标题: 色面棚拍
标签: 菜品, 棚拍
工具: 即梦
说明: 餐厅轮播封面用
---
这里写提示词正文……
```

在 SPT 里点卡片右上角的复制按钮，复制的就是正文。

## 3. 素材

**素材表**：一张表一个文件，比如 `素材/衣服.md`。每一行是一条素材：

```
| 编号 | 名称 | 写法 | 适合类型 | 来源 |
|---|---|---|---|---|
| Y001 | 冬日叙事 | 奶白色毛线帽，燕麦色大衣敞开…… | 叙事、约会 | 某某作品 |
```

- 第一列必须叫「编号」
- 要有一列叫「写法」（或「即梦写法」），复制的就是这一列
- 不想再用的那一行，在任意一格写上「不采用」，它会变灰

**素材图片和视频**：按类别放进子文件夹，例如 `素材/角色/Kaia/脸.png`。想写说明，就在旁边放一个同名的 `脸.md`。

## 4. 记录

日常记录、复盘、学到的东西，一篇一个 `.md`，文件名用 `日期-主题.md`，放进 `记录/`。

和某件作品有关的记录，写在那件作品里的 `记录.md`。

## 5. 便签

在 SPT 的「便签」页直接写就行。每个分组是 `便签/` 里的一个文件夹，每张便签是里面的一个 `.md` 文件；给便签写上日期，它就出现在月历的那一天，所以 Claude、Codex 也能搜到、能帮你写。撤下的便签收在 `便签/.已撤下/`，不会删除。

## 6. Skills

给 Claude、Codex 等 AI 用的技能，一个文件夹一个：`skills/名字/SKILL.md`。不用 AI 可以不管。电脑上你自己装的 Claude、Codex 技能，SPT 会自动显示，不用复制过来；它们自带的技能不显示。

## 不要放的东西

- 账号、密码、验证码截图、身份证件
- 删东西请拖进废纸篓，别直接永久删除
- 分享 SPT 给别人时，「打包分享」只带空的工作区，不会带走这里的作品
