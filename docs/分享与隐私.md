# 分享与隐私

公开仓库和 Release 发布包是空资料库，不包含使用者的作品、账号档案、密码、Cookie、token、登录状态、数据库或本机路径配置。

## 安装后会产生什么

| 位置 | 作用 | 能否公开分享 |
|---|---|---|
| `工作区/` 或自选工作区 | 自己的作品、提示词、便签、记录、发布回执和数据 | 逐项确认授权后再分享 |
| `data/` | 本机数据库、日志、队列和 Windows 浏览器资料 | 不公开分享 |
| `spt/settings.local.json` | 自己选定的工作区等本机设置 | 不公开分享 |
| `.venv/` | Windows 的 Python 依赖环境 | 无需分享，收件人重新安装 |
| macOS WebKit / Keychain 本机存储 | macOS 账号的浏览器会话 | 不导出、不作为发布包分发 |

平台登录由使用者在官方页面自行完成。Windows 浏览器会在本机保存会话，macOS 使用系统 WebKit 及相关本机存储；这属于自己使用后的本机状态，不会被放进公开发布包。软件不要求将密码写入工作区或交给 AI。

账号档案只是平台、名称等操作资料，不证明当前会话已经登录，也不替代发布前的身份核对。

## 分享给别人

推荐直接分享：

- [公开 GitHub 仓库](https://github.com/busyddbb/spt-studio-public)
- [最新 Release 下载页](https://github.com/busyddbb/spt-studio-public/releases/latest)

Windows 用户下载 `SPT-Windows-Portable.zip`；Mac 用户优先下载包含新建通用应用的 `SPT-macOS-Universal.zip`；需要完整源码和自行构建时，下载不含预编译应用的 `SPT-Universal-Source.zip`。这些包不带已安装的 Python 依赖：Windows 运行安装脚本，macOS 按首页说明安装 `requirements.txt`。Mac 应用使用通用身份 `local.spt.studio`，没有固定本机根路径，也不带原机登录状态。

不要把已经使用过的整个 SPT 文件夹直接压缩上传。即使工作区已经移空，`data/`、本机设置、日志、浏览器资料和备份中仍可能有私有内容。

## 备份与换电脑

备份实际工作区、`data/` 与本机设置时，只保存到自己控制的安全位置，不进入公开仓库。不要把数据库或浏览器会话作为故障反馈附件；反馈问题时，先检查日志、截图和路径里是否出现个人资料。

换电脑可以迁移自己的作品和普通记录；平台账号建议在新电脑重新登录。若自己制作示例作品包，使用虚构账号、虚构数据和拥有分享权的媒体。

## 发布与数据操作

自动发布必须先预览内容并授权本次任务。没有授权时，不应自动提交。媒体上传完成、审核中、已发布分别记录；结果不明时先检查官方后台，避免重复发布。

数据读取使用本机官方页面可见内容，不要求导出平台凭据。读不到的字段留空，登录过期或平台页面变化时显示原因。用户资料和平台状态不因软件测试通过而成为公开分享内容。
