# 本地发布路线

SPT 的资产管理和现有发布执行器在自己的电脑上运行，不要求购买第三方发布服务。

Windows 用本地 Chromium/Edge 执行器；macOS 用 SPT.app 的 WebKit 执行器。两者共用作品预览、明确授权、持久队列、排期、单次提交与结果回查。当前自动发布适配 rednote 图文和单视频，其他平台使用官方后台入口。

先完成自己的账号档案并在官方页面登录。登录资料由本机浏览器维护，不能随源码、作品或分享包分发。首次安装从空工作区开始。

安装、日常操作和数据读取见根目录 [使用说明](../使用说明.md)，Windows 见 [Windows 安装与使用](../安装与使用-Windows.md)。
