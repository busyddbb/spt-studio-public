# 给 agent

这是 SPT 资产库的根目录（库根目录）。动手前先读 `../spt/AGENTS.md`，或在上一级文件夹运行 `spt/bin/spt guide`。里面写了每类文件放哪里、怎么写。

- 给人看的存放说明是本目录的 `README.md`，规则和 `../spt/AGENTS.md` 一致。
- 找东西用 `spt/bin/spt search 关键词`（接了 MCP 就用 `spt_search`），不要整个目录逐个打开。
- 做好的作品用 `spt/bin/spt add` 收进来（见 `../spt/AGENTS.md`「收录做好的作品」）：只新增文件，不覆盖、不删除、不动原件。
- 写完文件运行 `spt/bin/spt reindex`，或请用户在 SPT 右上角点「刷新」。
- 发布、对外发送必须用户本人确认；账号密码不进库；删除走系统废纸篓。
